# CCTV THAI — กล้องสดทั่วไทย

เว็บแผนที่รวมกล้อง CCTV สาธารณะทั่วประเทศไทย คลิกหมุดกล้องแล้วดูวิดีโอสดได้ทันที
ใช้ได้ทั้งคอม, iPad, iPhone และ Android

- แผนที่เต็มจอ มีธีมให้เลือก 6 แบบ
- แถบรายชื่อกล้องด้านขวาพับได้ บนมือถือเป็นแผ่นเลื่อนขึ้นจากด้านล่าง
- โหมด **กล้องโปรด** ดูหลายกล้องพร้อมกัน 1, 4, 9 หรือ 16 ช่อง
- ตรวจกล้องทุกตัวอัตโนมัติทุก 30 นาที และซ่อนกล้องที่เสีย

## แหล่งกล้อง

| แหล่ง | จำนวนโดยประมาณ | ดูแบบไหน |
|---|---|---|
| iTIC / Longdo Traffic | ~170 | วิดีโอสด หรือภาพนิ่ง โหลดรายชื่อสดจาก Longdo ทุกครั้งที่เปิดเว็บ |
| กรมทางหลวง | ~60 | วิดีโอสด ผ่าน nginx relay |
| กรมทรัพยากรน้ำ | ~125 | วิดีโอสด (MJPEG) กล้องริมแม่น้ำ ส่วนหนึ่งออฟไลน์ |
| หาดใหญ่ City Climate | 32 | ภาพนิ่ง กล้องเฝ้าระวังน้ำท่วม |
| GISTDA เรดาร์ชายฝั่ง | 16 | วิดีโอสด ฝังจากหน้าเว็บ GISTDA |
| กทม. BMA Traffic (ตามแยก) | 609 | หมุดตำแหน่ง ลิงก์ไปเว็บ กทม. |
| เมืองพัทยา | 565 | หมุดตำแหน่ง ลิงก์ไปเว็บพัทยา |

> **ข้อควรทราบ:** ไม่มีแหล่งไหนประกาศเงื่อนไขการนำภาพไปใช้ต่อ และ iTIC ไม่ได้ออกใบอนุญาตไว้
> เว็บนี้ทำขึ้นเพื่อ**ใช้งานส่วนตัว** ถ้าจะเปิดเป็นเว็บสาธารณะหรือใช้เชิงพาณิชย์ ควรขออนุญาตเจ้าของกล้องก่อน

## ติดตั้ง

### สิ่งที่ต้องมี
- Docker 20+ พร้อม Docker Compose v2 (คำสั่ง `docker compose`)
- อินเทอร์เน็ต เว็บดึงภาพจากกล้องและแผนที่ตรงจากต้นทาง

### ขั้นตอน

1. คัดลอกโฟลเดอร์โปรเจกต์ไปไว้บนเครื่อง แล้วเข้าไปในโฟลเดอร์

   ```bash
   cd cctvbkk
   ```

2. สร้างไฟล์ตั้งค่า (ข้ามได้ถ้ามี `.env` อยู่แล้ว)

   ```bash
   cp .env.example .env
   ```

3. Build และเปิดระบบ

   ```bash
   docker compose up -d --build
   ```

4. เปิดเบราว์เซอร์ไปที่ `http://localhost:5455`
   มือถือหรือแท็บเล็ตที่ต่อ Wi-Fi วงเดียวกันเปิดได้ที่ `http://<IP ของเครื่อง>:5455`

ระบบมี 2 container:

| container | หน้าที่ |
|---|---|
| `cctvbkk` | nginx ให้บริการหน้าเว็บ และส่งต่อสตรีมกรมทางหลวงผ่าน `/proxy/doh/` |
| `cctvbkk-checker` | ตรวจกล้องทุกตัวทุก 30 นาที แล้วเขียนผลลง `status.json` |

### ตั้งค่า (`.env`)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `5455` | พอร์ตที่เปิดบนเครื่อง |

เปลี่ยนค่าแล้วรัน `docker compose up -d` ไม่ต้อง build ใหม่

### คำสั่งที่ใช้บ่อย

| ต้องการ | คำสั่ง |
|---|---|
| ดูสถานะ | `docker compose ps` |
| ดูผลตรวจกล้องล่าสุด | `docker logs --tail 10 cctvbkk-checker` |
| สั่งตรวจกล้องทันที | `docker compose restart checker` |
| build ใหม่หลังแก้ไฟล์ใน `cctv/` | `docker compose up -d --build` |
| หยุดระบบ | `docker compose down` |

## วิธีใช้งาน

### หน้าแผนที่
- **การ์ดซ้ายบน:** ช่องค้นหาถนน แยก หรือสถานที่
  - ปุ่ม **กรุงเทพฯ / ทั้งประเทศ** เลื่อนแผนที่ไปยังพื้นที่นั้น
  - ปุ่ม **▶ วิดีโอเท่านั้น** ซ่อนกล้องที่เป็นภาพนิ่งหรือลิงก์
  - เมนู **แหล่งกล้อง** เปิดหรือปิดแต่ละแหล่ง และมีตัวเลือก "แสดงกล้องที่ออฟไลน์"
- **หมุดกล้อง:** สีบอกแหล่งกล้อง
  - หมุดเล็กสีเทาคือกล้องที่ต้องเปิดดูที่เว็บต้นทาง
  - ขอบสีเหลืองคือกล้องโปรด
- **ปุ่ม ◐ ธีม:** เปลี่ยนแผนที่เป็น Glacier, Lagoon, Street, Night, Satellite หรือ OSM HOT

### แถบกล้องด้านขวา
- แสดงเฉพาะกล้องที่อยู่ในส่วนของแผนที่ที่กำลังดู เลื่อนหรือซูมแผนที่แล้วรายการเปลี่ยนตาม กล้องที่มีวิดีโอสดขึ้นก่อน
- คลิกการ์ดหรือหมุด วิดีโอจะเล่นที่ด้านบนของแถบ
- ปุ่มในตัวเล่น:
  - **⤢** ขยายเต็มจอ
  - **☆** เพิ่มเป็นกล้องโปรด
  - **×** ปิดตัวเล่น
- ถ้ากล้องไม่ส่งภาพภายใน 20 วินาที จะขึ้นข้อความพร้อมปุ่ม **ลองใหม่**
- ปุ่ม **›** พับแถบเก็บ บนมือถือใช้แถบจับด้านบนของแผ่นเลื่อน

### โหมดกล้องโปรด
1. กด **☆** ที่การ์ดกล้องหรือในตัวเล่น เพื่อเพิ่มเป็นกล้องโปรด
2. กดปุ่ม **★ กล้องโปรด** มุมขวาบน บนมือถือและ iPad ปุ่มอยู่ด้านล่าง
3. เลือกจำนวนช่อง 1, 4, 9 หรือ 16 กด × ที่มุมช่องเพื่อเอากล้องนั้นออก

กล้องโปรด ธีม และตัวกรองจำไว้ในเบราว์เซอร์แต่ละเครื่อง ไม่แชร์ข้ามเครื่อง

### ติดตั้งเป็นแอปบนมือถือ
- **iPhone / iPad:** เปิดด้วย Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android:** Chrome → เมนู ⋮ → **เพิ่มไปยังหน้าจอหลัก**
  - เว็บที่เป็น HTTP จะได้แค่ทางลัด ถ้าอยากติดตั้งเป็นแอปเต็มรูปแบบต้องใช้ HTTPS

## อัปเดตรายชื่อกล้อง

- **iTIC / Longdo** โหลดรายชื่อสดทุกครั้งที่เปิดเว็บ ไม่ต้องทำอะไร
- **แหล่งอื่น ๆ** ใช้รายชื่อที่ดึงเก็บไว้ในโฟลเดอร์ `sources/` วันที่ 27 ก.ย. 2569 แล้วรวมเป็น `cctv/data/cameras.json`

หลังแก้หรือเปลี่ยนไฟล์ใน `sources/` ให้รวมรายชื่อใหม่แล้ว build ใหม่:

```bash
python3 scripts/build_cameras.py
```

```bash
docker compose up -d --build
```

`scripts/build_cameras.py` จะข้ามกล้องกรมทางหลวงที่มีใน Longdo อยู่แล้ว และเก็บเฉพาะสตรีมที่ตอนดึงข้อมูลตอบกลับได้

ตัวตรวจกล้อง (`scripts/check_cameras.py`) รันเองได้ด้วย:

```bash
python3 scripts/check_cameras.py -v
```

- ตรวจกล้องทุกตัว แล้วพิมพ์สรุปว่าแต่ละแหล่งใช้ได้และเสียกี่ตัว
- ถ้าวิดีโอกล้อง iTIC เสียแต่ภาพนิ่งยังใช้ได้ หน้าเว็บจะแสดงภาพนิ่งแทน
- ตรวจด้วยว่าเว็บ BMA Traffic ของ กทม. กลับมาใช้ได้หรือยัง แล้วแสดงสถานะบนหน้าเว็บ

## โครงสร้างโปรเจกต์

```
.
├── docker-compose.yaml          # 2 services: cctvbkk (nginx) + checker
├── Dockerfile                   # nginx:alpine + ไฟล์เว็บ
├── .env / .env.example          # ตั้งค่า PORT
├── templates/
│   └── default.conf.template    # config nginx (พอร์ต 5455, /status/, /proxy/doh/)
├── cctv/                        # ไฟล์หน้าเว็บ (HTML/CSS/JS ล้วน ไม่มีขั้นตอน build)
│   ├── index.html
│   ├── app.js
│   ├── style.css
│   ├── manifest.webmanifest     # สำหรับติดตั้งเป็นแอป
│   ├── data/cameras.json        # รายชื่อกล้องที่รวมแล้ว
│   └── vendor/                  # Leaflet
├── scripts/
│   ├── build_cameras.py         # รวม sources/ → cctv/data/cameras.json
│   └── check_cameras.py         # ตรวจกล้อง → status.json
├── sources/                     # รายชื่อกล้องต้นฉบับจากแต่ละหน่วยงาน
└── dist/                        # เว็บพยากรณ์อากาศ "ฟ้าไทย" เดิม (ไม่เกี่ยวกับ CCTV THAI)
```

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `failed to create network ... all predefined address pools have been fully subnetted` | ช่วง IP ที่ Docker ใช้สร้าง network ถูกใช้หมดแล้ว compose ไฟล์นี้จึงใช้ `network_mode: bridge` อยู่แล้ว ถ้ายังเจอ ให้ลบ network ที่ไม่ใช้ด้วย `docker network prune` |
| เปิดเว็บแล้วขึ้น 403 | nginx อ่านไฟล์ไม่ได้ เพราะสิทธิ์ไฟล์ในเครื่องแคบเกินไป Dockerfile ตั้งสิทธิ์ไฟล์ให้ตอน build แล้ว ให้ลอง `docker compose up -d --build` อีกครั้ง |
| แผนที่ไม่ขึ้น | เครื่องต้องออกอินเทอร์เน็ตไปที่ `server.arcgisonline.com` ได้ ลองเปลี่ยนธีมเป็น OSM HOT |
| กล้องบางตัวไม่มีภาพ | กล้องต้นทางปิดหรือเสีย ตัวตรวจกล้องจะซ่อนให้ในรอบถัดไป ภายใน 30 นาที หรือสั่งตรวจทันทีด้วย `docker compose restart checker` |
| กล้องกรมทางหลวงไม่เล่น | สตรีมต้องผ่าน `/proxy/doh/` ของ nginx ในเครื่อง เช็กว่า container `cctvbkk` ออกอินเทอร์เน็ตได้ |
| หมุด กทม. เปิดแล้วเข้าเว็บไม่ได้ | เว็บ BMA Traffic ของ กทม. ล่มอยู่ ดูสถานะได้ในเมนู "แหล่งกล้อง" |
| หน้าเว็บยังเป็นเวอร์ชันเก่า | กด Ctrl+Shift+R หรือบนมือถือให้ล้าง cache ของเบราว์เซอร์ |
